## Methodology
The methodology implemented to conduct lagged relationship analysis displays a historical line graph showing the Pearson correlation between changes in FedFund Rates and changes to each macro-indicator metric generated from the .corr() function in Pandas. To keep the scope of the project manageable, I chose 8 quarters as the maximum length since extending beyond would be a choice that exposes the analysis to identifying a correlation with indicators that is harder to interpret as a result of targeted monetary policy. This analysis utilized a parameter search algorithm, which generated a lagged column for each FedFund Interest Rate interval, and then stored each Pearson coefficient for display.
